# 1.简介

这是一个Agent 示例 Plugin，仅适用个人学习使用，禁止用于生产环境

# 2.安装

```bash
/plugin install https://github.com/surmountme/agent-plugins
```

# 3.命令

`/hello`

用于向某个人进行友好的打招呼，并询问有什么可以帮到他

# 4.包含功能

- 1.提供Skill功能，用于向某个人进行友好的打招呼，并询问有什么可以帮到他
- 2.提供SubAgent功能，用于扫描源代码里面的安全漏洞，并生成结构化的漏洞
- 3.提供Hook功能，每次完成后停止后，立即进行测试，如果连续3次测试失败，则需要呼叫人工进行处理
